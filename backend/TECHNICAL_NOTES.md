# Technical notes — sources checked during the initial authentication implementation

> **Historical and implementation status (15 Oct. 2026).** The notes below record sources consulted on 1 Oct. 2026 during initial authentication work; they are not a claim that every described item remains the current implementation. The current stack is Next.js 16, React 19, NestJS 11, Prisma 7, PostgreSQL 17, and Supabase. BigQuery, Cloud Run, and Cloud SQL are not deployed. The site is unpublished; official submissions and GitHub delivery remain pending. Requirements RF01–RF06 are partially implemented; the calendar and exports are not complete. The reported test counts are 71 frontend and 48 backend tests. A later frontend coverage measurement, taken 15 Oct. 2026 at 15:55, reported 90.90% statements, 87.80% branches, 94.11% functions, and 96.06% lines. These figures do not establish a new build or completion of the pending work.

- NestJS rate limiting: the official guide uses `@nestjs/throttler`. The API configuration recorded at the time uses `ThrottlerModule.forRoot({ throttlers: [{ ttl, limit }] })`, binds `ThrottlerGuard` with `APP_GUARD`, and applies `@Throttle({ default: { limit, ttl } })` to individual routes. `ttl` is in milliseconds. Source: https://docs.nestjs.com/security/rate-limiting (consulted 1 Oct. 2026).
- Runtime observed: Node 22.13.0. `@nestjs/core` 11 declares Node >=20; Prisma ORM 7.10 declares Node `^20.19 || ^22.12 || >=24.0`. Sources: npm registry metadata for `@nestjs/core@11` and `prisma@7.10.0` (consulted 1 Oct. 2026).
- The initial `npm audit` identified vulnerable transitive packages in Prisma 7.10's CLI dependency graph: `deepmerge-ts` <8.0.0 (GHSA-ggr8-5vv4-36mx), `mysql2` <3.22.0 (GHSA-3f6p-5ww8-9rcr), and `mysql2` <=3.23.0 (GHSA-rgwj-5xj2-c3m3). The registry's suggested automatic fix downgraded Prisma to 6.19.3. Rather than force this major-version downgrade, the implementation tests explicit patched transitive overrides and Prisma CLI generation and validation before accepting them. Advisories: https://github.com/advisories/GHSA-ggr8-5vv4-36mx ; https://github.com/advisories/GHSA-3f6p-5ww8-9rcr ; https://github.com/advisories/GHSA-rgwj-5xj2-c3m3 (consulted 1 Oct. 2026).
