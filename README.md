# GFT Inteligente

Sistema web de gestão financeira e apoio à organização tributária para microempresas.

## Estado desta versão

Esta branch registra o estado do sistema até a **Entrega 3 (19/10/2026)** do PFC.

## Estrutura

- `backend/`: API NestJS, Prisma, autenticação, autorização, auditoria e regras financeiras.
- `frontend/`: aplicação Next.js, autenticação, dashboard, lançamentos, consulta cadastral e simulador tributário.

## Execução

Consulte os arquivos `backend/.env.example` e `frontend/.env.example` para configurar o ambiente. Não inclua arquivos `.env` ou credenciais no repositório.
